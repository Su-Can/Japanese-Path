# Japanese Path ｜ 日语学习路径

一个**纯前端、零依赖、可离线**的日语（A1）学习 Web 应用。打开即学，无需注册、无需服务器。

> 理念：**前端只做框架，课程内容由种子题库兜底、AI 按需增强**。在离线 / 无 API Key 时也能完整学完整个 A1。

---

## ✨ 功能特性

- **完整 A1 课程**：20 课 / 100 道选择题，覆盖 CEFR A1.1–A1.5 全部主题（自我介绍、问候、数字时间、饮食购物、家庭、交通、天气、时态、请求、比较、原因、能力等）
- **单元化路径**：课程按 5 个单元分阶展示，自动标记「即将解锁 / 学习中 / 已完成 / 当前课」
- **五十音图**：平假名 46 音图，点击即播放发音，附速记测验
- **发音朗读**：基于浏览器内置 Web Speech API（`ja-JP`），课程题目自动朗读、可重听
- **间隔重复复习**：按正确率计算复习周期（1/2/3 天），到期自动推送到「复习」页
- **高频错词**：自动收集易错表达，复习时重点强化
- **游戏化**：连续学习（Streak）+ 经验值（XP），驱动每日打卡
- **隐私优先**：所有学习数据仅存于浏览器本地（`localStorage`），无服务器、无追踪
- **AI 对话设置**：可填入 LLM API Key（仅存本地）并预览动态提示词

---

## 🚀 运行方式

无需安装、无需构建。二选一：

1. **直接打开**：双击 `index.html` 用浏览器打开即可
2. **GitHub Pages**：本项目已托管在 GitHub Pages，访问对应地址即可（仓库 `Su-Can/Japanese-Path`）

支持移动端与桌面端，移动端优先设计。

---

## 🛠 技术栈

| 项 | 说明 |
| :--- | :--- |
| 形态 | 单文件 SPA（仅 `index.html`，约 1280 行） |
| 语言 | 原生 HTML / CSS / JavaScript |
| 运行时依赖 | **零**（无框架、无打包、无 npm 包） |
| 存储 | `localStorage`（key: `japanesePathV2`） |
| 语音 | Web Speech API（`speechSynthesis`，朗读） |
| 部署 | 静态托管（GitHub Pages） |

## 📁 项目结构

```
Japanese-Path/
├── index.html   # 全部代码（UI + 样式 + 逻辑 + 题库）
└── README.md
```

课程与单元数据均内嵌在 `index.html` 的 `App.courses`（20 课）与 `App.units`（5 单元）中，便于直接编辑扩展。
