# Japanese Path ｜ 日语学习路径

一个**纯前端、零依赖、可离线**的日语（A1）学习 Web 应用。打开即学，无需注册、无需服务器。

> 理念：**前端只做框架，课程内容由种子题库兜底、AI 按需增强**。在离线 / 无 API Key 时也能完整学完整个 A1。

---

## ✨ 功能特性

- **完整 A1 课程**：20 课 / 100 道选择题，覆盖 CEFR A1.1–A1.5 全部主题（自我介绍、问候、数字时间、饮食购物、家庭、交通、天气、时态、请求、比较、原因、能力等）
- **单元化路径**：课程按 5 个单元分阶展示，自动标记「即将解锁 / 学习中 / 已完成 / 当前课」
- **五十音图**：平假名 46 音图，点击即播放发音，附速记测验
- **发音朗读**：基于浏览器内置 Web Speech API（`ja-JP`），课程题目自动朗读、可重听
- **间隔重复复习**：按正确率计算复习周期（1/2/3 天），到期自动推送到「复习」页
- **高频错词**：自动收集易错表达，复习时重点强化
- **游戏化**：连续学习（Streak）+ 经验值（XP），驱动每日打卡
- **隐私优先**：所有学习数据仅存于浏览器本地（`localStorage`），无服务器、无追踪
- **运行日志**：右下角 📋 浮动按钮可随时打开调试面板，实时记录 AI 请求、网络/CORS 错误、HTTP 状态码等，并支持**导出 .txt / 复制 / 清空**
- **AI 课程增强**：在「我的」页填入 API Key / Base URL / Model（默认兼容 OpenAI 格式，仅存本地），开启后 **按单元动态生成题目**——完成一个单元会用上一单元的薄弱项驱动下一单元出题，复习也按单元进行；未配置或生成失败自动回退内置种子题库

## 🚀 运行方式

无需安装、无需构建。二选一：

1. **直接打开**：双击 `index.html` 用浏览器打开即可
2. **GitHub Pages**：本项目已托管在 GitHub Pages，访问对应地址即可（仓库 `Su-Can/Japanese-Path`）

支持移动端与桌面端，移动端优先设计。

## 🤖 AI 课程增强 · 用法说明

AI 出题**默认关闭**，不影响离线学习。想用 LLM 动态生成题目时，按需配置：

1. 打开底部 **「我的」** 页，填写三个字段（均仅存于本机 `localStorage`，不上传任何服务器）：
   - **API Key**（必填）
   - **Base URL**（必填）：请求向其拼接 `/chat/completions`，例如填 `https://api.openai.com/v1` 即请求 `https://api.openai.com/v1/chat/completions`；Groq 填 `https://api.groq.com/openai/v1`，自托管代理填你的代理地址。
   - **Model**（默认 `gpt-4o-mini`，可改）
2. 点 **「测试连接」** 验证能否连通。
3. 进入任意课程，点顶部的 **「🤖 AI 增强：关」** 开关打开它。
   - 开启后该单元直接采用 AI 题；**完成一个整单元**时，会自动用上一单元的薄弱词驱动**生成下一单元**的题目。
   - 复习页按**单元**组织，到期单元点「开始复习」会顺序巩固该单元全部课程。
4. 任何网络/CORS/格式问题都会**自动回退内置种子题库**，不中断学习。

> ⚠️ **CORS 提示**：浏览器直连 OpenAI 官方域名通常会被跨域拦截。要让 AI 真正出得来，Base URL 请填**支持 CORS 的端点**（如 Groq）或**你自己部署的反向代理**（Cloudflare Worker / Vercel 等转发到上游）。这是浏览器安全限制，非应用 bug。

## 🐞 运行日志 · 调试入口

遇到 AI 不出题、连接失败、或界面异常时，不用开浏览器控制台：

- 右下角常驻 **📋 按钮**即是日志入口。点击展开**底部抽屉**，按 `INFO / OK / WARN / ERR` 分级实时显示日志；一旦发生错误，按钮会变红并显示红色角标（标着错误条数）。
- 日志会自动捕获并记录：
  - 应用启动、AI 配置保存（Base URL / Model；**API Key 只显示字符数，不泄露明文**）
  - 每次 AI 请求：目标地址、Model、**成功/失败、耗时、回复字符数**
  - 失败详情：区分**网络 / CORS 错误**（提示"可能是 CORS、地址错误或离线"）与 **HTTP 状态码 + 服务端返回内容**
  - **任何未被捕获的异常 / Promise 拒绝**（之前会静默消失，现在一律进日志）
- 抽屉内三个按钮：
  - **复制**：整份日志复制到剪贴板
  - **导出 .txt**：下载带时间戳的 `japanese-path-log-*.txt`（可附到反馈 / Issue）
  - **清空**：清空当前日志

> 日志与学习数据一样仅存于本机内存（不跨会话持久化，刷新页面即清空），不上传任何服务器。导出为 .txt 后可自行保管。
